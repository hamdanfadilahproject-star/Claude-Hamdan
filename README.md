# Claude-Hamdan

## Kantor AI — Virtual Office

Kantor virtual 3D isometrik berisi 14 agent AI yang bisa diberi tugas: chat per agent, rapat tim, meja persetujuan (desain grafis & video), papan tugas, brief harian, dan ekspor dokumen (Word, Markdown, Claude Docs).

- `index.html` — aplikasi lengkap dalam satu file (Three.js dimuat dari CDN).
- Fitur AI, Canva, unduhan, dan Claude Docs hanya aktif saat dibuka sebagai artifact di claude.ai.
